# Demokrat

Digitale Demokratie-Plattform -- Kooperative Stadtsimulation fuer politische Teilhabe.

## Tech Stack

- **Frontend:** Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** tRPC v11, Supabase (Postgres, Auth, Realtime)
- **Suche:** Meilisearch
- **Cache:** Upstash Redis
- **Karte:** Mapbox GL JS
- **Deployment:** Vercel

## Entwicklung

```bash
npm install
npm run dev
```
